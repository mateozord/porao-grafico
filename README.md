# Porão Gráfico

Plataforma de encomenda de serviços de design gráfico, com identidade visual dark e catálogo de trabalhos.

🔗 [porao-grafico.netlify.app](https://porao-grafico.netlify.app)

## Sobre

Desenvolvi este projeto para praticar React no front-end de uma loja/portfólio de serviços: catálogo de artes com lightbox, carrinho de compras e checkout.

## Tecnologias

- React + Vite
- Tailwind CSS
- Context API (carrinho de compras)

## Rodando localmente

```bash
npm install
npm run dev
```
